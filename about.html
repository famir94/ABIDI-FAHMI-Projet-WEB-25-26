Présentation du Projet

Ce site vitrine a été créé dans le cadre d'un projet académique au sein du département d'Informatique de l'EFREI. L'objectif principal était de concevoir et développer un site web professionnel et informatif présentant les formations, les valeurs et les objectifs du département d'Informatique.

Objectifs du Projet :

  • Créer une plateforme web moderne et responsive
  • Présenter les formations et spécialités du département
  • Mettre en avant l'excellence académique et l'employabilité
  • Faciliter la navigation et l'accès à l'information
  • Démontrer les compétences en développement web

Technologies Utilisées :

  • Frontend : HTML5, CSS3, JavaScript
  • Design : Responsive Design, Mobile-First
  • Outils : VS Code, Git, GitHub
