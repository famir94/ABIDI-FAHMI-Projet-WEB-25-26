# Site Vitrine - Département d'Informatique EFREI

## 📋 Description du Projet

Ce site vitrine a été créé dans le cadre d'un projet académique au sein du département d'Informatique de l'EFREI. L'objectif principal est de présenter le département, ses formations, et ses différentes spécialités de manière professionnelle et interactive.

## 🎯 Objectifs

- ✅ Créer une plateforme web moderne et responsive
- ✅ Présenter les formations et spécialités du département
- ✅ Mettre en avant l'excellence académique et l'employabilité
- ✅ Faciliter la navigation et l'accès à l'information
- ✅ Démontrer les compétences en développement web

## 📱 Responsive Design

Le site est entièrement responsive avec des points de rupture optimisés:
- **Desktop** : 1200px et plus
- **Tablette** : 768px - 1199px
- **Mobile** : moins de 768px
- **Petit Mobile** : moins de 480px

## 💻 Comment Utiliser

### Ouverture du Site
1. Ouvrir `index.html` dans un navigateur web
2. Naviguer entre les pages via la barre de navigation
3. Tester le carrousel sur la page d'accueil

### Structure des Fichiers
- Tous les fichiers HTML sont à la racine
- Les assets (CSS, JS, images) sont dans le dossier `assets/`
- Pas de serveur requis pour une visualisation locale

## 📝 Contenu à Personnaliser

Pour adapter le site à votre projet:

1. **Mettre à jour les noms** dans `about.html`:
   ```html
   <h3>[Nom du Membre]</h3>
   ```

2. **Ajouter des images**:
   - Placer les images dans `assets/images/`
   - Mettre à jour les URLs dans le code

3. **Modifier le contenu** des formations dans `courses.html`

4. **Ajouter plus de membres** à l'équipe

5. **Mettre à jour les coordonnées** dans la section contact

## 🔧 Personnalisation Avancée

### Modifier les Couleurs
Éditer les variables CSS dans `assets/css/style.css`:
```css
:root {
    --primary-color: #003d82;
    --secondary-color: #0066cc;
    --accent-color: #ff6b35;
    /* ... etc */
}
```

### Ajouter du Contenu
- Ajouter des sections dans les fichiers HTML
- Créer de nouvelles classes CSS en suivant la convention existante
- Maintenir la structure BEM pour la lisibilité
