# Projet Web TI402 - Site Vitrine EFREI

## Description 
Le but de ce projet est de coder un site vitrine  pour présenter le département d'informatique de l'efrei, de la création de la maquette jusqu'au code final.

## Structure du Projet
Voici comment on a organisé nos fichiers :
* `index.html` : Page d'accueil 
* `courses.html` : Liste détaillée des formations (Licence, Master, etc.)
* `about.html` : Présentation de l'équipe et de notre méthode de travail
* `contact.html` : Formulaire de contact et nos infos (on a aussi intégré des boutons de réseaux sociaux interactifs)
* `space.html` : Un faux espace membre avec un calendrier dynamique
* `gallery.html` : Une galerie photo
* `css/style.css` : Tout notre design centralisé
* `js/` : Nos scripts 
 * `images/` : Les logos et photos du site

##  Fonctionnalités principales
On a essayé de mettre en pratique tout ce qu'on a vu en cours, et on a rajouté quelques trucs sympas en plus :
* **Responsive :** Le site s'adapte aux écrans d'ordinateur, tablettes et téléphones (utilisation de Flexbox et Grid).
* **Carrousel interactif :** Un slider d'images sur l'accueil qui tourne tout seul toutes les 5 secondes (géré en JS).
* **Formulaire de contact :** Vérification en direct pour voir si les champs sont bien remplis avant l'envoi.
* **Réseaux Sociaux :** Ajout de boutons avec des petits effets CSS interactifs au survol sur la page Contact.
* **Animations CSS :** Des petits effets au survol sur les boutons et les cartes pour rendre le site un peu plus vivant.

##  Technologies utilisées
Comme demandé dans les consignes, on n'a utilisé aucune bibliothèque externe :
* HTML5
* CSS3
* JavaScript
