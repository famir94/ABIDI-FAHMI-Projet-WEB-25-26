# Galerie d'Images - Placeholder

Ce dossier contient les images utilisées sur le site. Les images placeholder ci-dessous sont des suggestions :

## Images Recommandées

### Pour la page d'accueil (carrousel)
- **hero1.jpg** : Campus EFREI ou image représentative tech
- **hero2.jpg** : Image de classe/collaboration
- **hero3.jpg** : Innovation/technologie

### Pour les pages de contenu
- **department.jpg** : Vue du département
- **team.jpg** : Photo d'équipe
- **student.jpg** : Étudiant au travail
- **lab.jpg** : Laboratoire informatique

## Comment ajouter des images

1. Placez vos fichiers image dans ce dossier
2. Utilisez le chemin `assets/images/nom-du-fichier.jpg` dans le HTML
3. Ajouter l'attribut `alt` pour l'accessibilité

## Formats supportés
- JPG/JPEG (photos)
- PNG (graphiques)
- WebP (optimisé web)
- SVG (logos/icônes)

## Optimisation

Pour optimiser vos images :
1. Compressez les fichiers avant upload
2. Utilisez des dimensions appropriées (max 1200px de large)
3. Convertissez en WebP si possible pour le web

Outils recommandés :
- TinyPNG/TinyJPG
- ImageOptim
- Squoosh (Google)
